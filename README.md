# qwen-coder — DocCheck

Система анализа и проверки проектной и рабочей документации по инженерным системам
(электроснабжение, электроосвещение, АПС / СОУЭ / пожаротушение, СКС / ЛВС / ВОЛС,
видеонаблюдение, СКУД, охранная сигнализация, АСУ / АСУТП) на соответствие
действующим НТД и законодательству Российской Федерации.

## Возможности

- **Базовый набор функций:** приём документов `xls/xlsx, doc/docx, pdf, dwg/dxf`;
  детерминированные проверки (кабельный журнал ↔ спецификация, длины трасс на планах
  с учётом способов прокладки, схемы ↔ спецификация, выбор кабеля по марке и сечению
  согласно ПУЭ/ГОСТ/СП, расчёты источников питания по току и мощности, подбор АКБ,
  сверка прилагаемых расчётов); анализ нейросетями в режимах `local / cloud / hybrid`.
- **База НТД:** 15 нормативных документов, автоматическая проверка актуальности
  перед каждой проверкой документации.
- **Правила для нейросети (вшиты в промпты):** 1) при нехватке исходных данных ничего
  не придумывать — запросить недостающее; 2) о непроведённых проверках сообщать с
  указанием причины; 3) отвечать как есть, без домыслов.
- **Отчёт:** перечень выполненных/невыполненных проверок, замечания со ссылками на
  пункты НТД, разделение на критические и некритические, выводы; сохранение в `docx`
  и `xlsx`; ведомость объёмов работ и ведомость оборудования и материалов в `xlsx`.
- **Веб-интерфейс:** тёмная тема, загрузка файлов, выбор режима и моделей ИИ,
  просмотр/корректировка базы НТД, диалоговое окно хода проверки, чат с ИИ.
- **Администрирование:** аутентификация по логину/паролю; управление пользователями
  (добавление, удаление, смена пароля, блокировка); ручное добавление/удаление
  облачных моделей через веб и API `/api/models`.

## Установка

Полная инструкция — в файле **[INSTALL.md](INSTALL.md)**. Кратко:

```bash
sudo bash install.sh          # единый скрипт установки (Debian 12 / Ubuntu 22.04+)
```

- Адрес после установки: `http://<IP-сервера>:5000`
- **Логин администратора:** `admin`
- **Пароль по умолчанию:** `Admin123!` (задаётся/меняется при установке через `.env`)

## Структура проекта

```
app/                Flask-приложение (routes/, services/, templates/, static/)
data/               SQLite БД и загруженные файлы
scripts/            unit-тесты и smoke-тесты
install.sh          единый скрипт установки на сервер
INSTALL.md          подробная инструкция по установке
Dockerfile          образ для контейнерного запуска (CPU-only)
gunicorn.conf.py    конфигурация продакшен-сервера
wsgi.py             точка входа
```

## Бесплатные модели ИИ (для CPU 8 ядер / 24 ГБ RAM)

Локально (Ollama): `qwen2.5:3b-instruct`, `phi3:mini`, `deepseek-r1:1.5b`, `llama3.2:3b`.
Облачно (бесплатные тарифы): OpenRouter `meta-llama/llama-3.1-8b:free`,
Groq `llama-3.3-70b-versatile`. Список можно расширять вручную через интерфейс «Модели ИИ».

## Конфигурация сервера (целевая)

Proxmox → LXC/VM: CPU 8 ядер (AMD FX-8120), RAM 24 ГБ, SSD 60 ГБ, GPU не требуется.
